# System behaviour migration map

Вспомогательная проверка консолидации, не часть основной рабочей спецификации. Источник: System As-Is v1 frozen и authoritative frozen component specs. Все ссылки ведут к документам спецификаций; production code не использовался.

Coverage: MIGRATED — факт/flow, условное последствие или нерешённый вопрос размещён в новом сценарии/разделе; COMPONENT_ONLY — техническая деталь остаётся у компонента; EVIDENCE_ONLY — свидетельство происхождения/проверки, не поведение приложения. MIGRATED не означает исправление риска, решение OPEN или принятие As-Is как To-Be.
