# System reference map

Этот файл не является частью читаемой System Specification. Он используется агентами и CHECK-процессом для навигации от System scenario/model к техническим specifications и frozen evidence. Обычная ручная работа с System SPEC не требует чтения этого файла.

Индекс не является source of truth: Server As-Is authoritative для технических фактов Server, Android As-Is — Android, frozen System As-Is — межкомпонентного поведения. Рабочая System Model задаёт канонические системные определения. Противоречие между источниками требует явного сообщения, а не самостоятельного решения.

## Историческая migration map

[system-behavior-migration-map.md](system-behavior-migration-map.md) сохранена без изменений как свидетельство первоначального переноса 26 CAP / 12 FLOW / 4 MISMATCH / 19 RISK / 21 OPEN. Её прежние рабочие пути и ID относятся к историческому состоянию; это не активная навигация. Для перехода к нынешнему сценарию из старого System ID нужно убрать конечный числовой суффикс и использовать таблицу выше.

Определение SYNCED и таблица состояний очереди перенесены в System Model. Identity authorities остаётся правилом границ в 07-system-rules-and-recovery. Ссылки из прежних четырёх вспомогательных разделов также сохранены выше. Исторические component/frozen IDs внутри подписей не переименованы.

## Граница проверки

Этот рефакторинг использует только specifications. CHECK как сверка с production code здесь не выполнялся. Известные mismatch/risk/OPEN не разрешены редактурой; ограничения и вопросы сохранены рядом со сценариями. Новых противоречий между прочитанными authoritative specifications при извлечении модели не обнаружено.
