# Карта PhotoCloud

## Что такое PhotoCloud

PhotoCloud копирует доступные фотографии Android-устройства в персональное хранилище Server. Android обнаруживает изображения, ведёт очередь и отправляет содержимое. Server управляет аккаунтами, проверяет доступ, ведёт каталог файлов и хранит принятые байты.

## Участники

| Участник | Роль |
| --- | --- |
| Пользователь | Настраивает соединение, регистрируется и входит, разрешает чтение изображений, смотрит локальный результат |
| Android | Обнаруживает фото, вычисляет checksum, проверяет наличие и отправляет файлы |
| Server | Проверяет права, ведёт файлы и папки, хранит содержимое |
| Почтовая инфраструктура | Доставляет письма активации и сброса пароля; подтверждение выполняется вне Android |
| ОС и хранилище устройства | Определяют видимые изображения, доступные байты, разрешения и условия фонового исполнения |

## Модель и границы

[System Model](01-system-model.md) определяет сущности и поля. В пути фотографии различаются изображение устройства, локальная запись Android, удалённый логический файл, StoredObject и физические байты Server. Это разные объекты со своими identity и жизненным циклом.

Текущая синхронизация направлена от устройства к Server. Обратной сверки, переноса удалённых изменений на устройство и распространения удаления нет. Android Files показывает локальную очередь; удалённая галерея, скачивание и управление Server файлами/папками в Android отсутствуют. Возможность Server принимать видео и другие типы не означает наличие Android video backup.

Backup обозначает направление копирования. Точный критерий локального успеха — [SYNCED](01-system-model.md#synced); он не устанавливает гарантий внешнего резервирования Server. Границы источников системных фактов описаны в [общих правилах](07-system-rules-and-recovery.md#identity-authorities).
