# Совместный доступ и владение

## 1. Доступ к собственным файлам и папкам

**Status:** AS-IS  
**Availability:** SERVER_ONLY  
**System:** [ACCESS-OWNER](../system/06-sharing-and-access.md#access-owner)

Файлы и папки удалённой библиотеки принадлежат конкретному пользователю. При обращении к объекту Server проверяет его принадлежность текущему аккаунту; чужой объект не открывается как доступный пользователю.

## 2. Совместный доступ и публичные ссылки

**Status:** AS-IS  
**Availability:** NOT_PRESENT  
**System:** [SHARING-ABSENT](../system/06-sharing-and-access.md#sharing-absent) · [FILES-COPY](../system/05-file-library.md#files-copy)

Совместного доступа как функции PhotoCloud сейчас нет. Пользователь не может поделиться файлом или папкой с другим аккаунтом, создать публичную ссылку, выдать отдельные права чтения/изменения или использовать общую папку/семейную библиотеку.

Обычное копирование файла создаёт независимую серверную копию и не является sharing. Внутренние структуры Server, которые технически допускают несколько ссылок на данные, также не образуют доступную пользователю функцию совместного доступа.
