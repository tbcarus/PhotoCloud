# System capability matrix

System IDs относятся к end-to-end либо system-significant возможностям. IMPLEMENTED описывает механизм **в указанном scope**, не полную сохранность или runtime certification. PARTIAL фиксирует существенные ограничения полного flow; STUB — доступную заглушку; NOT PRESENT — отсутствие функции в текущей системе Android+Server. UNUSED не применён: наличие Server-only API не делает отсутствующую Android функцию «end-to-end inactive».
