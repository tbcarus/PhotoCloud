# System risks

Риски — возможные негативные последствия As-Is при указанных условиях, не произошедшие инциденты и не fixes. Severity назначена на system consequence: HIGH — существенная потеря backup/доступа/согласованности/конфиденциальности; MEDIUM — ограниченная эксплуатационная потеря или задержка. Это не CVSS и не автоматический максимум component severity. RISK ссылается на mismatch как источник условия, не заменяет его описание.
